
# Scissors - URL Shortening Website

## About the Project

Scissors is a URL shortening website designed to help users create shorter, more manageable links.

This project was built as part of my frontend development learning journey.

## Built With

- HTML5
- CSS3

## Features

- Navigation bar
- Hero section
- URL shortening form
- Pricing section
- Frequently Asked Questions
- Responsive footer

## Getting Started

To view the project:

1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
